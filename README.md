# 📁 Document Management System (DMS)

### Digital Document Scanning, Renaming & Validation Platform

**Document Management System (DMS)** is a web-based platform designed to digitize, organize, rename, validate, and manage documents through a centralized workflow.

## ✨ Key Features

* 📄 Document Scanning & Upload
* ✏️ Structured Document Renaming
* ✅ Document Validation
* 📂 Organized Document Management
* 🔍 Easy Document Retrieval
* 👥 Supervisor-Based Workspaces
* 📊 Document Processing Workflow
* 🖥️ User-Friendly Interface
* ⚡ Faster Digital Record Management

## 🔄 Workflow

```text
Scan / Upload
      ↓
Document Processing
      ↓
Rename
      ↓
Validation
      ↓
Organized Storage
      ↓
Easy Retrieval
```

## 🛠️ Technology Stack

**PHP • MySQL • HTML • CSS • JavaScript • Bootstrap**

# 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/HussainMehdiIqbal/Document-Management-System-.git
```

### 2. Move Project to XAMPP

Copy the project folder into:

```text
C:\xampp\htdocs\
```

### 3. Start XAMPP

Open **XAMPP Control Panel** and start:

```text
Apache
MySQL
```

### 4. Create Database

Open:

```text
http://localhost/phpmyadmin
```

Create a new database and import the project's `.sql` database file.

### 5. Configure Database

Update the database connection file with your local MySQL credentials:

```php
$servername = "localhost";
$username   = "root";
$password   = "";
$database   = "your_database_name";
```

### 6. Run the Project

Open your browser and visit:

```text
http://localhost/Document-Management-System-/
```
